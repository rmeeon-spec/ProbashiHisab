প্রবাসী হিসাব — Android APK তৈরির প্রজেক্ট

এই ZIP-এ Android Studio-তে খোলার মতো সোর্স প্রজেক্ট আছে।
এটি APK ফাইল নয়; এই পরিবেশে Android SDK/Gradle দিয়ে APK কম্পাইল করা সম্ভব হয়নি।

APK বানানোর নিয়ম:
১) কম্পিউটারে Android Studio ইনস্টল করুন।
২) এই ZIP Extract করুন।
৩) Android Studio > Open দিয়ে ProbashiHisab ফোল্ডারটি খুলুন।
৪) Gradle Sync শেষ হতে দিন (প্রথমবার ইন্টারনেট লাগতে পারে)।
৫) Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
৬) APK সাধারণত app/build/outputs/apk/debug/app-debug.apk-এ পাওয়া যাবে।
৭) APK ফোনে পাঠিয়ে ইনস্টল করুন। প্রয়োজনে Android Settings থেকে এই উৎসের Install unknown apps অনুমতি দিন।

অ্যাপের সুবিধা:
- তারিখসহ সৌদি রিয়ালে বেতন এন্ট্রি
- প্রতি এন্ট্রিতে বিনিময় হার সংরক্ষণ
- বাংলাদেশে পাঠানো টাকার তারিখ ও পরিমাণ
- বাংলাদেশে খরচের খাতভিত্তিক হিসাব
- মাসভিত্তিক সারাংশ
- JSON ব্যাকআপ ডাউনলোড/রিস্টোর

গুরুত্বপূর্ণ:
- হিসাব এই ফোনের অ্যাপ ডাটায় থাকে; অ্যাপের ডাটা ক্লিয়ার/আনইনস্টল করলে হারাতে পারে।
- নিয়মিত ব্যাকআপ ডাউনলোড করে নিরাপদে রাখুন।
- বিনিময় হার নিজে লিখবেন; অ্যাপ স্বয়ংক্রিয় ব্যাংক রেট আনে না।
